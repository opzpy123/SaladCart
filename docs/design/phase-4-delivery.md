# Phase 4 — Cross-platform delivery gate

## Scope

- Version the workstation as 0.2.0 across npm, Cargo and Tauri.
- Keep a reproducible Windows compile gate (`pnpm check:windows`) and a CI workflow.
- Standardize release steps in `docs/release-checklist.md`.
- Produce the macOS artifact with checksums and a versioned release note.

## Versioning

`package.json`, `src-tauri/Cargo.toml` and `src-tauri/tauri.conf.json` all report
`0.2.0`; `Cargo.lock` is regenerated by the build. The version is shown in Settings and
the browser mock.

## Cross-platform gate

`scripts/check-windows.mjs`:

- creates a temporary empty FFmpeg sidecar so Tauri's resource validation can run;
- runs `cargo xwin check --target x86_64-pc-windows-msvc` on macOS/Linux, or a native
  `cargo check` on Windows;
- uses a resource-compiler shim only for the `check` build script when `llvm-rc` is not
  installed; it never builds a bundle;
- cleans up the placeholder and shim on exit.

CI: `.github/workflows/windows-check.yml` runs the same gate on Ubuntu with cargo-xwin.

## Release gate

`docs/release-checklist.md` covers pre-flight, automated tests, native macOS walkthrough,
the Windows runtime gate, artifact hashing, tag-driven draft release, and rollback.
