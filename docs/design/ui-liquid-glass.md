# UI 设计规范：Liquid Glass（0.4.0）

0.4.0 将工作台从「暖色纸张 + 橄榄绿」改为参考 macOS 26 / iOS 26 的 Liquid Glass 视觉体系。目标是让原生桌面工作台更像系统应用：冷色半透明材质、清晰的层级、系统蓝作为唯一主交互色，绿色只保留给「完成 / 就绪」状态与品牌标识。

## 设计原则

1. **内容优先**：玻璃只用于导航、浮层和容器边框，正文区域保持高对比，不让模糊效果吃掉可读性。
2. **系统化而非拟物**：使用系统字体、系统蓝、系统圆角与阴影；不描边、不渐变文字、不额外装饰。
3. **单一主色**：蓝色承担所有可点击、选中、进度与焦点；绿色只表达成功；琥珀色只用于节拍 / 警告。
4. **原生性能**：`backdrop-filter` 只挂在大面积容器上，动画只使用 transform / opacity，并尊重 `prefers-reduced-motion`。

| Token | 值 | 用途 |

| `--panel-strong` | `#fbfbfd` | 不透明卡片 / 弹层内容 |
| `--ink` | `#1d1d1f` | 主文字 |
| `--muted` | `#6e6e73` | 次级文字 |
| `--accent` | `#0a84ff` | 主交互色（系统蓝） |
| `--accent-strong` | `#0071e3` | 按下 / 深色链接 |
| `--good` | `#30d158` | 成功状态点 |
| `--good-ink` | `#248a3d` | 成功文字 |

画布使用固定的蓝 / 紫 / 绿三色径向光晕叠加在冷灰底色上，随窗口尺寸铺满，不参与滚动，避免滚动时背景闪烁。

## 字体

- UI：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI Variable Text", "PingFang SC", "Microsoft YaHei"`。
- 展示：`--font-display`，同族 Display 字重，用于页面大标题、Hero 和统计数字。
- 标题启用负字距（`-0.02em` ~ `-0.04em`），正文保持系统默认字距。
- 中文回退到苹方 / 微软雅黑，保证 macOS 与 Windows 一致的字形节奏。

## 材质与形状

- 面板：`backdrop-filter: blur(24px) saturate(160%)`，22px 圆角，1px 白色内高光（inset）模拟玻璃边缘。
- 弹层：28px 圆角，`blur(42px)`，深色半透明遮罩（`rgba(17,19,14,0.5)`）再加模糊。
- 侧栏：深色半透明玻璃，选中项为蓝色渐变胶囊；项目切换器同为玻璃材质。
- 按钮：主按钮为蓝色渐变胶囊，次按钮为玻璃胶囊，按下时 `scale(0.98)`。
- 输入框：聚焦时冷白底 + 2px 蓝色光环（`box-shadow`）。
- 卡片：悬停上浮 2px 并加深阴影，仅用于角色 / 分镜 / 素材卡片。

## 组件映射

| 区域 | 处理 |
| --- | --- |
| 侧栏 | 深色玻璃；蓝色选中态；底部状态点保留绿 / 红语义 |
| 顶栏 | 半透明磨砂，滚动时保持可读 |
| 概览 Hero | 大号中文标题 + 玻璃海报叠层 + 玻璃上下文卡 |
| 剧本 / 角色 / 分镜 | 白色玻璃面板，蓝色选中行，绿色成功徽标 |
| 剪辑时间线 | 蓝色音乐轨与波形、蓝色播放头、琥珀节拍标记、绿色字幕、紫色配音 |
| 弹层 | 28px 玻璃弹层，深色模糊背景 |
| 设置 | 玻璃分组卡片，蓝色开关与焦点环 |

## 动效

- 页面进入：`opacity + translateY(8px)`，`--ease-spring`（`cubic-bezier(0.22,1,0.36,1)`），约 320ms。
- 卡片悬停：`transform: translateY(-2px)`。
- 按钮按下：`scale(0.98)`。
- `prefers-reduced-motion: reduce` 时关闭进入动画与悬停位移。

## App 图标（0.4.1）

- 概念：玻璃购物车 + 三颗透光蔬果（青柠、翡翠、番茄红），对应「沙拉车」；不使用文字。
- 结构：深松绿到青色的玻璃底、左上薄荷极光、右下蓝紫微光；购物车为透明磨砂玻璃，白色高光描边，柔和接触阴影。
- 约束：最多三个主体色球，无叶片、无额外道具；32px 仍需可辨轮廓。
- 母版：`public/brand/icon.png`（1024×1024，圆角外透明）。
- 全平台尺寸由 `pnpm tauri icon public/brand/icon.png` 生成；桌面端使用 `src-tauri/icons/{32x32,128x128,128x128@2x,icon.icns,icon.ico}`。
- 已在 32 / 40 / 64 / 128px 下检查轮廓，应用内 Logo、启动页与设置页共用同一母版。
