# 抖音热门参考

## 数据源边界

抖音没有公开、免鉴权的“热门视频”HTTP API。直接抓取抖音网页需要签名/反爬绕过，可能违反平台条款，因此 SaladCart **不内置爬虫**。

本功能读取用户在 **设置 → 抖音热门参考** 配置的 HTTPS 数据源，适用于：

- 抖音开放平台中已申请 `hotsearch` / 热门视频榜 scope 的授权接口；
- 你已有的第三方数据服务或内部聚合接口；
- 任何返回统一 JSON 结构的授权接口。

访问令牌以 Bearer 发送，保存在系统钥匙串，不写入项目或日志。后端只允许公网 HTTPS、拒绝 localhost/私网地址和重定向，响应上限 2 MB。

## 接口约定

支持数组直接返回，或嵌套在 `data` / `result` / `list` 等对象中。每个条目至少要有标题字段：

```json
{
  "data": {
    "list": [
      {
        "title": "热门话题",
        "hot_value": 123456,
        "url": "https://www.douyin.com/...",
        "cover": "https://..."
      }
    ]
  }
}
```

字段兼容：

| 用途 | 可用字段 |
| --- | --- |
| 标题 | `title`、`word`、`hotword`、`hot_word`、`name`、`keyword`、`sentence`、`content` |
| 热度 | `hot_value`、`hot`、`hotindex`、`heat`、`score`、`play_count`、`view_count`、`hot_score`（支持 `万` / `亿` 后缀） |
| 链接 | `url`、`share_url`、`link`、`schema` |
| 封面 | `cover`、`cover_url`、`image`、`pic` |

后端按数组顺序取前 20 条；不推断平台热度，不伪造数据。

## 建议生成

“生成参考建议”会把当前项目的立意、类型、气质和前 10 条热榜标题交给默认编剧模型（需真实 DeepSeek/兼容 LLM），要求输出：

- 5 个方向的 3 秒钩子、30 秒结构、角色反转、标题和照搬风险；
- 3 个可立即写入剧本的冲突点。

系统提示明确要求把热榜当作受众信号，不复制或改编原视频的具体情节、台词和角色。建议只用于创作参考，不自动改动剧本。

## 使用

1. 在 **设置 → 抖音热门参考** 填入授权接口 URL（HTTPS）和 Bearer 令牌（可选）。
2. 回到概览点 **抖音热门参考**，刷新热榜。
3. 点 **生成参考建议**；可复制结果。

若未配置数据源，弹层会提示去设置，不会回退到网页抓取或 Mock 热榜。
